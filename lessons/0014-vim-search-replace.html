vim 搜索与替换

这一课学 vim 里最常用的两件事：找一个词、换掉一批词。全内置、不用插件。你的 .vimrc 还开了两个好设置（第 8、15、16 行），让搜索更顺手。

搜索

在 normal 模式敲 /，后面跟要搜的词，Enter：

命令效果
/词向下搜索，光标跳到第一个匹配
n跳到下一个匹配
N跳到上一个匹配

你的配置开了 incsearch（增量搜索）——敲 / 后边打字，光标就边跳边亮，不用等回车；还开了 hlsearch——搜完所有匹配都高亮。

清除高亮

搜完那一堆高亮还赖在屏幕上，很烦。你的配置第 204 行给了个键：Ctrl+l = 清除所有搜索高亮（等于 :nohlsearch）。记住这个键，每次搜完按一下。备用命令：敲 :noh 回车，效果一样。

替换

格式是 :s/旧词/新词/，前面加范围、结尾加标志：

命令效果
:s/旧/新/当前行第一个「旧」→「新」
:s/旧/新/g当前行所有「旧」→「新」
:%s/旧/新/g全文所有「旧」→「新」
:%s/旧/新/gc全文替换，但每个都问你确认（y/n）

记法：% = 全文（整个文件），g = 每一处（不只在行首），c = confirm（逐个确认）。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. v /tmp/test.txt——打开文件。
  2. 按 o 进 insert，打一行 foo bar foo bar foo，Esc 回 normal。
  3. 敲 /foo Enter——光标跳到第一个 foo，所有 foo 高亮。
  4. 按 n、n——跳到下两个 foo；N 往回跳。
  5. 按 Ctrl+l——高亮消失。
  6. 敲 :s/foo/bar/g Enter——当前行所有 foo 变 bar。
  7. 按 u 撤销，再敲 :%s/foo/bar/gc——体验逐个确认（y 替换 / n 跳过）。
主要来源

搜索替换是 vim 内置，见 :help /、:help :substitute。你配置里的 incsearch/hlsearch 和 Ctrl+l 见 vim/.vimrc 第 8、15、16、204 行。上一课：0013 · vim 导航（fzf）。
