改得动 ①：修 vim 系统剪贴板

进入第二阶段「改得动」——不再只是用，而是理解原理、动手修。第一课修最值的：系统剪贴板。修好后 空格+y（复制）、空格+p（粘贴）就能在 vim 和浏览器/别的程序之间互通了。

现象

空格+y 复制、空格+p 粘贴没反应。因为它们绑的是 "+ 寄存器（系统剪贴板），而你的 vim 编译时没带系统剪贴板支持。

原理：-clipboard 但留了钩子

先看 vim --version 里的两个词：

  • -clipboard —— 没编译进系统剪贴板，所以 "+ 寄存器默认是死的；
  • +clipboard_provider —— 但留了个钩子：允许你用 vimscript 函数「接管」"+/"*，通过外部命令读写剪贴板。

你的机器是 X11（DISPLAY=:0）且装了 xclip，所以写一个「xclip provider」接上钩子，"+ 就活了。

诊断（以后自己查这三条）

vim --version | grep -i clipboard    " 看 +clipboard 还是 -clipboard、有没有 provider 钩子
command -v xclip xsel wl-copy        " 看装了哪个剪贴板工具
echo $DISPLAY                        " X11 还是 Wayland（决定用 xclip 还是 wl-copy）

改法：.vimrc 加一段

在 .vimrc 里加（逐段看懂，别盲抄）：

" 系统剪贴板（vim 9.x clipboard provider，桥接 xclip）
function! ClipboardAvailable() abort
    return executable('xclip')
endfunction

function! ClipboardCopy(reg, type, lines) abort
    call system('xclip -selection clipboard', join(a:lines, "\n"))
endfunction

function! ClipboardPaste(reg) abort
    return ['', systemlist('xclip -selection clipboard -o')]
endfunction

let v:clipproviders['xclip'] = {
    \ 'available': function('ClipboardAvailable'),
    \ 'copy': {'+': function('ClipboardCopy'), '*': function('ClipboardCopy')},
    \ 'paste': {'+': function('ClipboardPaste'), '*': function('ClipboardPaste')},
    \ }
set clipmethod^=xclip
  • ClipboardAvailable：告诉 vim「xclip 在不在」，不在就跳过这个 provider；
  • ClipboardCopy：vim 把要复制的内容传进来，用 system('xclip …', 内容) 塞进系统剪贴板；
  • ClipboardPaste：用 systemlist('xclip -o') 读出剪贴板，返回 [类型, 行列表] 给 vim；
  • v:clipproviders['xclip'] = {…}：把三个函数注册成 provider，+/* 两个寄存器都接上；
  • set clipmethod^=xclip：把 xclip 设成首选 provider。

验证

  1. vim 里选中一段，按 空格+y，切到浏览器 Ctrl+V 粘贴——看有没有；
  2. 从浏览器复制一段，回 vim 按 空格+p——看有没有。

检验一下（原理理解）

现在就练（真实世界步骤）

  1. v ~/.vimrc（或 vim .vimrc）打开配置。
  2. 找个空行，把上面那段粘进去，:w 保存。
  3. 重启 vim，或 :so % 重新加载当前文件。
  4. 按上面「验证」两步，测试复制和粘贴两个方向。
