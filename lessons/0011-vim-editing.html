vim 编辑：插入、删除、撤销、复制粘贴

上一课你会进、会动、会存、会退了。这一课学会改内容——这是编辑文件的最小闭环。所有操作都在 normal 模式下敲（除了插入）。

插入：四种位置

键在哪里开始打字
i光标前
a光标后
o下面新开一行
O上面新开一行

你这套配置的映射（.vimrc 第 107–108 行）：normal 模式下按 Enter = o 后立刻 Esc——下面开新行，但停在 normal 模式（不进入 insert）。所以想「开行 + 直接打字」用 o；想「开行 + 停在 normal」敲回车。

注意：配置文件还写了 nmap <S-Enter> O<Esc>（上方开新行），但在终端里触发不了——终端把 Shift+Enter 和 Enter 当同一个键发送，vim 无法区分，两者都走 <CR> 这条（下面开新行）。上方开新行请用 O。

删除

键删什么
x光标处的一个字符
dd光标所在的整行

规律：连按两次的（dd）作用在「行」上；单个的（x）作用在「字符」上。

撤销与重做

键效果
u撤销上一步
Ctrl+r重做（撤销的撤销）

新手最安心的两个键——改错了按 u 就行，vim 能撤销很多很多步。

复制粘贴

键效果
yy复制（yank）整行
p粘贴到光标下方
P粘贴到光标上方

dd 删掉的行也会进剪贴板——所以「剪切一行」= dd 再 p。巧的是 yy（复制）和 dd（删除）就差一个字母，很好记。

快速移动（配合编辑用）

键移到
w / b下一个 / 上一个单词
0 / $行首 / 行尾
gg / G文件开头 / 结尾

检验一下（检索练习）

现在就练（真实世界步骤）

  1. v /tmp/test.txt——打开昨天的文件。
  2. 按 o——下面新开一行并进入 insert，打一句话，Esc 回来。（注意：直接按 Enter 只开行、不进入 insert。）
  3. 按 dd——删掉这一行；按 u——撤销，行回来了。
  4. 按 yy 然后 p——复制并粘贴一行，看到多出一行。
  5. 按 x——删掉光标处一个字符。
  6. 用 w / 0 / $ / gg / G 快速移动光标。
  7. Ctrl+s 保存，Ctrl+q 退出。
