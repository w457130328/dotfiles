vim-surround：改引号、加括号

这一课学 tpope 的 vim-surround 插件——解决一个超高频需求：给文字加/删/换「环绕符」（引号、括号、HTML 标签）。比如把 "foo" 改成 'foo'，或给 foo 套上 (foo)。插件已加载，直接能用。

三个命令

命令含义例子结果
cschange surround 换环绕cs"'"foo" → 'foo'
dsdelete surround 删环绕ds""foo" → foo
ysyou surround 加环绕ysiw"foo → "foo"

用法：光标停在 环绕符之间的文字上（比如 "foo" 的 foo 上），再敲命令。

⚠️ 括号的开闭有大区别

这是最容易踩的坑——左括号和右括号效果不同：

你敲结果
ysiw(( foo )（带空格）
ysiw)(foo)（不带空格）

记法：左括号 = 留空间，右括号 = 贴紧。[ ]、{ } 同理。

几个真实例子

  • cs"'——双引号换单引号（写 Python 时常用）。
  • cst"——把 HTML 标签换成引号（t 代表标签）。
  • ysiw)——给光标处的词套上括号，如 foo → (foo)。
  • ds(——去掉括号（连里面的空格一起清掉）。
  • yss"——给整行加引号（ss = 整行）。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. v /tmp/test.txt，按 o 打一行："hello world"，Esc 回 normal。
  2. 光标停在引号内的文字上，按 cs"'——双引号变单引号。
  3. 按 ds'——单引号消失。
  4. 光标停在 hello 上，按 ysiw)——变成 (hello)。
  5. 按 cs] 或 cs( 试试换别的括号，体会左/右的区别。
  6. 按 ds(——括号没了。
