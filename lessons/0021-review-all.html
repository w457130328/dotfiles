总复习：i3 + zsh + vim 三阶段

这是间隔重复。用法：看每一行的场景，先盖住答案、凭记忆回想键位/命令，想不起来再点开看答案。答错的在旁边记一笔，之后重点重练。

阶段 1 · i3（Mod = Super 键）

打开终端？

Mod + Return

关闭当前窗口？

Mod + q

切到工作区 3？

Mod + 3（Mod+0 = 工作区 10）

把窗口搬到工作区 3？

Mod + Shift + 3

水平分屏 / 垂直分屏？

水平 Mod + z，垂直 Mod + v

移动焦点（往左/下/上/右）？

Mod + h / j / k / l

移动窗口（往左/下/上/右）？

Mod + Shift + h / j / k / l

窗口浮动 / 取消浮动？

Mod + Shift + Space

全屏？

Mod + f

调整窗口大小？

Mod + r 进 resize 模式 → h/j/k/l 调 → Esc 退出

启动应用（rofi）？

Mod + g（run）

常用应用快捷键？

chromium Mod+Alt+1、firefox Mod+Alt+2、intellij Mod+Alt+3、spotify Mod+Alt+5

标签式布局？

Mod + w

退出 i3（注销）？

Mod + Shift + q

阶段 2 · zsh

打印当前日期？

Ctrl + T

打印 Unix 时间戳？

Esc 再 Ctrl + T（两步）

快速看 git 状态？

Ctrl + G

管道后缀「翻页 / 过滤 / 取前几行」？

L（less）、G（grep）、H（head）

管道后缀「格式化 JSON」？

Fj（jq .）

git：状态 / 提交 / 加全部？

gst / gcmsg / gaa

⚠️ git 两个坑：gcm 和 gs 是什么？

gcm = checkout main（不是 commit）；gs = git show（不是 status）

普通别名：cat / vim / source 配置？

c / v / sz

后缀别名：.jar / .zip / .pdf 会怎样？

.jar 直接运行、.zip 列内容、.pdf 用 mupdf 打开

阶段 3 · vim（leader = 空格）

保存 / 退出？

Ctrl + s / Ctrl + q

新 buffer / 切下一个 / 切上一个 / 关 buffer？

空格+t / 空格+l / 空格+h / 空格+bd

切回上一个 buffer？

空格 + 空格

方向键的作用（normal 模式）？

←/→ 切 buffer，↑/↓ 滚屏

找文件 / 搜内容 / 文件树？

空格+n（fzf Files）/ 空格+f（Rg）/ 空格+x（Explore）

搜索 + 下一个 + 清除高亮？

/词、n、Ctrl + l

全文替换？

:%s/旧/新/g

当前行下移 / 上移？

Ctrl + j / Ctrl + k

粘贴代码防缩进乱？

Ctrl + p（paste 模式）

切换自动换行？

空格 + w

改引号/加括号/删括号？

cs / ys / ds（vim-surround）

看撤销历史树？

:UndotreeToggle，然后 Ctrl+w h 切进面板

展开代码片段 + 跳占位符？

触发词 + Tab；跳下一个 Tab，跳回 Shift+Tab

英文标题转大写？

空格 + c

ASCII 大字（能用的那个）？

空格 + 1（带边框；2/3 你的机器缺字体会报错）

英文拼写检查？

Ctrl + ]
