git 别名

这一课学你最该记住的一组缩写——git。它们来自 oh-my-zsh 的 git 插件（你的 .zshrc 第 74 行 plugins=(git) 已加载），所以这些 g 开头的缩写开箱即用，不用改配置。你在 dotfiles 这个 git 仓库里直接就能练。

高频 8 个（记住就够用了）

别名展开成做什么
gstgit status看状态（有改动吗）
gssgit status --short状态，一行一文件
gagit add暂存文件
gaagit add --all暂存全部
gcmsggit commit -m提交（带消息）
gcogit checkout切分支 / 恢复文件
gbgit branch列分支
gdgit diff看改动差异

另有 gp（push）、gl（pull）、gcob（checkout -b 建新分支）也常用，用到再记。

⚠️ 两个必踩的坑

这俩是新手最容易搞混的，因为「看着像」：

  • gcm 不是 commit！它展开是 git checkout $(git_main_branch)——切回主分支。提交是 gcmsg（commit -m）。别在 gcm 后面跟提交消息，那是错的。
  • gs 不是 status！你的配置里 gs = git show（看某个提交），看状态是 gst。这是你 .aliases 第 99 行自定义的，覆盖了直觉。

一句话口诀：提交用 gcmsg，状态用 gst，主分支用 gcm。

检验一下（检索练习）

现在就练（真实世界步骤）

就在 dotfiles 仓库里，敲下面这些只读命令（不会改任何东西，放心）：

  1. gst——看到当前有修改的文件（你之前改过 i3/vim/zsh 等）。
  2. gss——同样的状态，但一行一个文件，更紧凑。
  3. gd——看具体改了什么（q 退出 diff 分页）。
  4. gb——列出所有分支。
  5. gcm——切回主分支（当前应该就在 master，会提示 already）。体会一下它不是 commit。
主要来源

这些别名是 oh-my-zsh git 插件的默认定义，完整列表见 oh-my-zsh git 插件。你自定义的 git 别名见 zsh/.aliases 第 99–116 行。上一课：0008 · 普通别名与后缀别名。
