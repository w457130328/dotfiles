vim buffer 多文件切换（leader = 空格）

前两课你会在单个文件里编辑了。这一课学会在多个文件之间来回切换——这是真正干活时最常用的动作。它全靠一个核心设定：leader = 空格键。

什么是 buffer

vim 打开一个文件，把它读进内存，这份内存叫 buffer（缓冲区）。你可以同时打开好几个文件——它们各自是一个 buffer，在后台排着队，你随时切换。注意：buffer ≠ 窗口，你看不到所有 buffer，但它们在等你。

所以「切换文件」=「切换 buffer」。你这套配置把切换动作全绑在了 空格 上。

leader = 空格

.vimrc 第 105 行 let mapleader = "\<Space>"：空格被设为 leader（前缀键）。意思是你先按一下空格，再按另一个键，就触发自定义命令。下面所有「空格+xx」都是这个套路——先敲空格，松开，再敲后面的字母。

buffer 切换键（都是 空格+xx）

键效果
空格+l下一个 buffer（向右）
空格+h上一个 buffer（向左）
空格+空格切回刚才那个 buffer（来回跳）
空格+bl列出所有 buffer（:ls）
空格+bd关闭当前 buffer
空格+t新建一个空 buffer

怎么记

  • l / h 就是「右 / 左」——和你已经会的 hjkl 方向一致：向右 = 下一个，向左 = 上一个。
  • bd = buffer delete（删 buffer）、bl = buffer list（列 buffer）——英文缩写，好记。
  • 空格+空格 最常用：在两个文件间快速来回跳，敲两下空格就行。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. 造两个文件：echo one > /tmp/a.txt && echo two > /tmp/b.txt。
  2. 一次打开两个：v /tmp/a.txt /tmp/b.txt——vim 显示第一个，第二个在 buffer 里。
  3. 空格+l——切到 b.txt；空格+h——切回 a.txt。
  4. 空格+空格——在两个文件间来回跳几下。
  5. 空格+bl——看到所有 buffer 列表（每个前面有编号）。
  6. 空格+bd——关闭当前 buffer，切到剩下的那个。
  7. Ctrl+q 退出。
主要来源

这些映射见 vim/.vimrc 第 105、139–157 行。buffer 概念见 :help buffers。上一课：0011 · vim 编辑。
