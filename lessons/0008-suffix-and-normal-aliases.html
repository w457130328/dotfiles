普通别名与后缀别名

前两课学了全局别名（管道后缀）。这一课补全剩下的两类，你就把 zsh 三种别名都掌握了。它们都定义在 zsh/.aliases。

三种别名各管一段

类型写法展开位置例子
普通别名alias c='cat'只能替换命令开头c 文件 → cat 文件
全局别名alias -g L='| less'命令任何位置ps aux L → ps aux | less
后缀别名alias -s pdf='…'按文件名后缀触发报告.pdf → 自动用 pdf 程序打开

普通别名：命令开头的缩写

先记这几个高频的（都在命令开头敲）：

别名展开成用途
ccat看文件内容
vvim编辑文件
v.vim .用 vim 打开当前目录
leless -j4分页看（q 退出）
szsource ~/.zshrc重载配置（改完 .zshrc 必用）
hhash -rf清空命令路径缓存

其中 sz 最值得记——你以后改任何 zsh 配置，改完敲 sz 就生效，不用重开终端。

后缀别名：敲文件名就自动打开

这是 zsh 独有的（bash 没有）。机制：当你敲的「命令」其实是一个带已知后缀的文件名时，zsh 就按后缀补上对应的打开命令。比如：

敲 t.zip → zsh 看到 .zip → 执行 unzip -l t.zip

你不用敲 unzip -l，直接敲文件名就行。定义长这样（见 zsh/.aliases 第 299–307 行）：

alias -s {zip,ZIP,war,WAR}="unzip -l"
alias -s {jar,JAR}="java -jar"
alias -s gz="tar -tf"
alias -s {pdf,PDF}='background mupdf'   # ← 这种会失败，见下

⚠️ 你的机器上，哪些后缀别名能用

作者的后缀别名分两类：

  • 命令行查看（unzip -l / java -jar / tar -tf）——能用，因为这些命令装了。
  • 后台打开图形程序（background mupdf / gpicview / chromium / vlc / libreoffice）——全都失效，因为那几个程序你这台机器没装。

background 是作者自定义的函数（autocomplete.zsh 第 47 行），作用是把程序放到后台跑、不占住终端——所以打开 PDF 后终端还能继续敲命令。但程序没装，函数再巧妙也白搭。

所以现在你只需要记住三个能用的后缀：.jar、.zip、.gz。

检验一下（检索练习）

现在就练（真实世界步骤）

普通别名：

  1. 敲 c zsh/.aliases——直接打印别名文件内容。
  2. 敲 le zsh/.aliases——分页看，q 退出。
  3. 敲 sz——看到提示符刷新（重载配置，无害）。

后缀别名（用 tar 造测试文件——zip 命令没装，但 tar/unzip 都在）：

  1. cd /tmp && echo hi > t.txt——造一个文件。
  2. tar czf t.tar.gz t.txt——打包成一个 tar.gz。
  3. 直接敲 t.tar.gz——不用 tar 命令，看到 tar 内容清单。
  4. tar czf t.tgz t.txt——再试 .tgz 后缀，效果一样。
  5. 直接敲 t.tgz——同样列出内容。
