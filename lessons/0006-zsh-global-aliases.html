zsh 全局别名：管道后缀

进入 zsh。这一课学你这套配置里最省事的东西——全局别名（管道后缀）：敲一个字母，代替一整个 | 命令。这是"用得顺"里回报率最高的一课。

普通别名 vs 全局别名

先分清两种别名，这是本课的地基：

  • 普通别名（alias c='cat'）：只能替换命令开头。你敲 c 文件 → cat 文件。
  • 全局别名（alias -g L='| less'）：能在命令任何位置展开。你敲 ps aux L → ps aux | less。这是 zsh 独有（bash 没有）。

你的配置用全局别名做了一组管道后缀——把最常用的 | 命令 缩成一个字母，见 zsh/.aliases 第 239–251 行。

核心管道后缀

先记住这几个高频的（用法：在命令末尾直接敲字母）：

别名展开成用途
L| less分页查看
H| head只看开头几行
G| grep过滤匹配行
C| clipcopy结果复制到剪贴板
Fj| jq .JSON 格式化

这些后缀还能串联。一个真实例子：

ps aux G java L 等价于 ps aux | grep java | less——列出所有进程，过滤含 java 的，再分页看。

敲三个字母 G 省掉 | grep ，再敲 L 省掉 | less。这就是全局别名的力量。

检验一下（检索练习）

现在就练（真实世界步骤）

打开终端，逐条敲，看结果和展开后是否一致：

  1. 敲 ps aux G java——等价于 ps aux | grep java，看到含 java 的进程。
  2. 敲 ps aux G java L——分页查看，q 退出。
  3. 敲 ls /usr/bin H——只显示前 10 行。
  4. 敲 echo 你好 C——然后 Ctrl+V 粘贴，验证"你好"已进剪贴板。
  5. 敲 echo '{"a":1}' Fj——看到 JSON 被格式化。
主要来源
