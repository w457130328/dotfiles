vim 导航：找文件、搜内容（fzf）

这一课学 vim 里最值钱的三个导航键——它们让你不用记住文件在哪、代码在哪，敲几个字母就跳过去。全挂在 leader（空格）上，定义在 .vimrc 第 169–171 行。

三个导航键

键命令用来干什么
空格+n:Files按文件名找——你知道文件名，模糊打几个字母
空格+f:Rg按内容搜——你知道文件里有什么字，搜关键字
空格+x:Explore浏览目录树——不确定要找什么，一层层逛

怎么用 fzf（前两个键）

空格+n 或 空格+f 会弹出 fzf 的模糊搜索框：

  • 直接打字——列表实时过滤，不用打全名，打中间几个字母就行。
  • Ctrl+j / Ctrl+k（或上下键）——上下移动选择。
  • Enter——打开选中的文件 / 跳到选中位置。
  • Esc——取消，回到 vim。

两个的区别（容易混）

  • :Files（空格+n）搜的是文件名——比如你记得有个文件叫 shortcuts，打 short 就筛出来。
  • :Rg（空格+f）搜的是文件内容——比如你想找「哪里用了 bindkey」，打 bindkey，列出所有含它的行，回车直接跳到那一行。

记法：n = name（名字）、f = find（找内容）、x = eXplore（浏览）。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. cd ~/Projects/dotfiles 然后 v .——用 vim 打开这个项目目录。
  2. 空格+n——输入 zshr，看到 .zshrc 被筛出来，Enter 打开。
  3. 空格+n——输入 alias，看到 .aliases，打开它。
  4. 空格+f——输入 bindkey，列出所有含 bindkey 的行，上下选一个，Enter 跳过去。
  5. 空格+x——打开文件树，Enter 进目录，再 Enter 打开文件（- 返回上一级）。
  6. Ctrl+q 退出。
