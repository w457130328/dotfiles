i3 是什么，以及你的前 5 个键

这一课只做一件事：让你不看任何表，用键盘完成「开终端 → 切焦点 → 切工作区 → 关窗口」这一套最小操作流。学完它，你就已经能脱离鼠标在 i3 里正常干活了。

i3 一句话

i3 是一个平铺式窗口管理器（tiling window manager）：窗口自动铺满屏幕、不重叠，所有操作都靠键盘完成，鼠标是可有可无的。它的设计理念是「手不离开键盘」。官方用户指南把它概括为一句话：i3 is a tiling window manager, completely written from scratch.

三个心智概念

动手之前，先记住三个词——它们是你理解后面所有快捷键的地基：

  • Mod 键：几乎所有快捷键的「前缀」键。你的配置里写的是 set $mod Mod4（见 config），Mod4 就是 Super/Win 键。以后凡是写 Mod+某键，都指「先按住 Win 键」。
  • 工作区（workspace）：i3 有 10 个虚拟桌面，编号 1–10，用 Mod+1…0 切换。每个工作区是一组窗口的「容器」。
  • 焦点（focus）：在平铺布局里，同时只有一个窗口是「激活」的（边框高亮），你的键盘输入只进到它那里。移动焦点 = 决定「接下来操作哪个窗口」。

你的前 5 个键

注意：i3 默认方向键是 jkl;，但你这套借用来的配置改成了 Vim 式 hjkl（config 第 73–76 行）——这跟你用 Vim 的习惯一致，是好事。

操作按键作用
开终端Mod+Enter打开 alacritty，一切从这里开始
移动焦点Mod+h/j/k/l焦点移到 左/下/上/右 的窗口
切换工作区Mod+1…0跳到工作区 1–10（0 是第 10 个）
关闭窗口Mod+q优雅地关掉焦点窗口（走 _i3-graceful-kill）
系统菜单Mod+Shift+Esc弹出关机/锁屏/重启菜单，再按 h 关机、l 锁屏

现在就练（真实世界步骤）

别只是读——现在就在你的 i3 里把这套动作完整走三遍：

  1. 按 Mod+Enter 开一个终端。
  2. 再按两次，开出三个终端；用 Mod+h/j/k/l 在它们之间来回移动焦点，观察哪个窗口边框高亮。
  3. 按 Mod+2 切到空白工作区，开一个终端，再按 Mod+1 切回来。
  4. 用 Mod+q 逐个关掉刚才开的所有窗口。
  5. 按 Mod+Shift+Esc 打开系统菜单，再按 Esc 退回（先别真的关机）。
