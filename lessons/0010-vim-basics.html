vim 基础：模式、移动、保存退出

从这一课起进入 vim——三块里最需要「肌肉记忆」的一块。你的 vim 是 Daschner 的 .vimrc 配好的。第一课只解决一件事：能进 vim、能移动光标、能改字、能保存、能退出。这几样会了，后面所有高级键才有地基。

地基一：两种模式

vim 和普通编辑器最大的区别——它有「模式」。理解不了这个，其他全白搭：

模式此时敲键是怎么进去
normal（普通）命令（移动、删除、退出…）按 Esc
insert（插入）文字（正常打字）按 i / a / o

vim 打开时默认在 normal 模式——所以你会遇到「敲字没反应、还哔哔叫」，那是你在 normal 模式下把字母当命令了。想打字，先按 i。

地基二：移动光标（手不离键盘）

在 normal 模式下，用这四个键移动，不用方向键（方向键又慢又要手离开主键盘区）：

      k        上
  h ←  → l     h=左  l=右
      j        下

和 i3 的 hjkl 是同一套，你已经会了。

地基三：保存与退出（这套配置给你的快捷键）

你的 .vimrc 第 190–191 行把保存/退出绑到了两个超好记的键：

按键效果
Ctrl+s保存（:w）
Ctrl+q退出（:q）

备用标准命令（记不住 Ctrl 组合时用）：:w 保存、:q 退出、:wq 保存并退出、:q! 放弃改动强行退出。

小提醒：万一 Ctrl+s 让屏幕「冻住」了（个别终端的流控制问题），按 Ctrl+q 解冻，改用 :w 保存即可。alacritty 一般不会，但你知道这个兜底。

预告：leader = 空格键

这套配置最核心的一个设定（.vimrc 第 105 行 let mapleader = "\<Space>"）：leader 键是空格。后面你会看到一大堆 空格+xx 的快捷键——找文件、切 buffer、复制到系统剪贴板，全都挂在空格上。现在先记住「空格是总开关」，下一课开始逐个讲。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. 敲 v /tmp/test.txt——用别名打开 vim，进入 normal 模式。
  2. 按 i——进入 insert 模式，打几行字。
  3. 按 Esc——回到 normal 模式。
  4. 用 hjkl 移动光标，体会「手不离开键盘」。
  5. 按 Ctrl+s——保存，左下角看到 "/tmp/test.txt" written。
  6. 按 Ctrl+q——退出 vim。
