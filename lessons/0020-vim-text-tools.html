vim 特色工具：拼写、标题、大字

最后一课，三个「写作 / 装点」类的小工具，都是这套配置的特色。日常写英文文档、做演示标题时会用到。

① 拼写检查：Ctrl+]

Ctrl+] = 切换英文拼写检查（:set spell!）。开启后，拼错的英文单词会高亮。写完英文 README / 邮件按一下检查，查完再按一下关掉。

② 标题大写：空格+c

空格+c = 把当前行（或 visual 选中的文字）转成 AP 风格的英文标题（重要词首字母大写，介词/连词保持小写）。

a river runs through the city  →  A River Runs Through the City

用法：光标停在标题行上，按 空格+c。visual 模式选中多行也能一起转。

③ ASCII 大字：空格+1 / 2 / 3

把当前行文字变成 toilet 风格的 ASCII 大字，三种样式：

键样式
空格+1带边框（-f term -F border）✅ 能用
空格+2标准字体（-f standard）⚠️ 你的机器缺字体，报错
空格+3小字体（-f small）⚠️ 同样缺字体，报错

适合给笔记、README、演示加个大标题。你的 Arch 上 toilet 没有 standard/small 这两个字体名，所以 空格+2/3 会报 could not load font，只有 空格+1 能用。想救活需把字体名换成 mono12/smmono12（改得动，先记着）。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. v /tmp/test.txt，o 打一行 a river runs through the city。
  2. 光标停在这行，按 空格+c——变成 A River Runs Through the City。
  3. 再 o 打一行 hello world，按 空格+1——变成带边框的 ASCII 大字。
  4. 按 Ctrl+] 开拼写，随便打个错词（如 teh），看它高亮；再按一次关掉。
