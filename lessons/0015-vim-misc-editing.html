vim 编辑增强：移动行、粘贴模式、换行

三个日常编辑的小工具，都是这套配置绑好的（见 .vimrc 第 131–153 行）。一次学三个，因为它们都简单。

① 移动行：Ctrl+j / Ctrl+k（核心）

键效果
Ctrl+j当前行下移一行
Ctrl+k当前行上移一行

记法：j=下、k=上（和你熟的 hjkl 方向一致）。用途：调整代码 / 列表 / 文字的顺序，不用「剪切 → 移动光标 → 粘贴」三步，一行直接搬走。

三种模式都支持：normal 模式搬整行；visual 模式选中多行一起搬；insert 模式也能搬（会闪一下切到 normal 再回来，正常）。

② 粘贴模式：Ctrl+p

Ctrl+p = 切换 paste 模式（:set paste!）。什么时候用：从浏览器 / 别处粘贴一大段缩进好的代码时，vim 的自动缩进会把内容越缩越深、乱成一团。按一下 Ctrl+p 进 paste 模式再粘贴，就原样保留；贴完再按一下切回来。

③ 换行：空格+w

空格+w = 切换自动换行（:set wrap!）。你的配置默认 nowrap（不换行，长行会超出屏幕）。看长文档 / 长文章时按一下让它换行，写代码时再按一下关掉。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. v /tmp/test.txt——打开文件，用 o 打三行：aaa、bbb、ccc（各一行）。
  2. 光标停在 aaa，按 Ctrl+j——它下移；按 Ctrl+k——它又上移。
  3. 按 V 进 visual 选中两行，Ctrl+j——两行一起下移。
  4. 按 Ctrl+p 切 paste 模式，从别处粘贴一段代码，再 Ctrl+p 切回。
  5. 按 空格+w——观察长行换行；再按一次——恢复。
