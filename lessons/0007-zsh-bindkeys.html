zsh 快捷键（bindkey）

上一课学的别名帮你少打字，这一课学的快捷键帮你少敲命令——按一个键，直接完成「清屏 + 列目录」「插入日期」「git status」这些高频动作。它们定义在 shortcuts.zsh，通过 bindkey 绑定。

这 6 个快捷键

都在 emacs 模式下生效（zsh 默认模式，你的 .zshrc 没改成 vi 模式）：

按键效果
Ctrl+K清屏，并列出当前目录（exa -al）
Ctrl+J清屏，并显示 2 层目录树（tree -L 2）
Ctrl+H清屏，并显示 3 层目录树（tree -L 3）
Ctrl+T在光标处插入当前日期（ISO 8601）
Esc 再 Ctrl+T在光标处插入 Unix 时间戳（秒）
Ctrl+G清屏，并显示 git status

最实用的两个

  • Ctrl+T：写文档、写 commit 时要填日期，不用背今天的日期，按一下自动插进去。
  • Ctrl+G：在 git 仓库里想看状态，一个键就出 git status（你这 dotfiles 目录就是 git 仓库，直接就能试）。

提醒：这些键覆盖了 zsh 的默认行为——比如 Ctrl+K 默认是「删除到行尾」、Ctrl+T 默认是「交换相邻字符」。这套配置把它们改成了上面的功能。所以别惊讶这些键「不是你以为的那样」。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. 在提示符后按 Ctrl+T——光标处会插入今天的日期。
  2. 按 Ctrl+K——清屏并列出当前目录文件。
  3. 按 Ctrl+J——清屏并显示 2 层目录树。
  4. 在任意 git 目录（比如这个 dotfiles）按 Ctrl+G——直接看到 git status。
  5. 先按 Esc 松开，再按 Ctrl+T——插入一串数字（Unix 时间戳）。
