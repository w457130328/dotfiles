UltiSnips：代码片段

这一课学 UltiSnips——帮你把几个字母展开成一大段代码模板。比如敲 sec 再按一下 Tab，就长出标题 # … #；敲 main + Tab，就长出 Java 的 main 方法。省去一遍遍手打样板代码。

关键概念：snippet = 触发词 + 占位符

  • 触发词：几个字母（如 sec、cbl、main），敲完按 Tab 就展开。
  • 占位符：展开后的模板里，光标会自动停在第一个「空位」上等你填；填完按 Tab 跳下一个空位，最后跳到结尾。

三个键

键作用
Tab展开 snippet（有匹配时）
Tab跳到下一个占位符
Shift+Tab跳回上一个占位符

配置见 .vimrc 第 67–69 行。Tab 身兼两职：有 snippet 匹配就展开，没有就退回普通的自动补全（supertab，等于 Ctrl+n）。

⚠️ snippet 认文件类型

snippet 是按文件类型加载的：markdown 的 snippet 只在 .md 文件里有效，Java 的只在 .java 里有效。所以练习时要用对扩展名——文件名结尾决定一切。

几个常用的（markdown）

敲展开成
sec + Tab# … #（一级标题）
ssec + Tab## … ##（二级标题）
sssec + Tab### … ###（三级标题）
cbl + Tab``` … ```（代码块）
link + Tab[文字](http://链接)（链接）
img + Tab![说明](路径)（图片）

代码类的（Java 举例）

你装了 IntelliJ，写 Java 时会用到这两个：

敲展开成
cl + Tabpublic class 文件名 { }（类骨架）
main + Tabpublic static void main(String[] args) { }

Python 的 def、class、ifmain，Shell 的常用片段同理，都在对应的 snippet 文件里。等你写那种语言时再翻不迟。

检验一下（检索练习）

现在就练（真实世界步骤）

  1. v /tmp/test.md（注意 .md 扩展名，否则 markdown 片段不生效）。
  2. 敲 sec 然后 Tab——长出 # Section Name #，光标选中 Section Name。
  3. 直接打字 我的标题（替换占位符），按 Tab——光标跳到标题末尾。
  4. 按 o 开新行，敲 ssec + Tab——二级标题，填 小节。
  5. 再 o，敲 cbl + Tab——长出代码块，打几行字。
  6. 再 o，敲 link + Tab——长出链接模板，用 Tab 在「文字」和「网址」之间跳着填。
  7. 试着 Shift+Tab 往回跳，体会占位符的来回。
