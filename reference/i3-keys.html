i3 核心键位速查表

Mod = Super / Win 键（配置里 set $mod Mod4）。这套配置用 Vim 式 hjkl 方向键。打印出来贴桌上，用于间隔复习。

注意：配置里 workspace_layout tabbed（config 第 10 行）——新工作区默认是标签页布局，不是平铺。想平铺就按 Mod+e。

注意：chromium / intellij-idea-ultimate-edition / spotify 未安装，Mod+Alt+1/3/5 失效；开浏览器用 Mod+Alt+2（firefox）或 Mod+g 搜 firefox。

浏览（0001）

操作按键
开终端Mod+Enter
移动焦点 左/下/上/右Mod+h/j/k/l
切换工作区 1–10Mod+1…0
关闭焦点窗口Mod+q
系统菜单（关机/锁屏/重启）Mod+Shift+Esc，再按 h/l/r

组织布局（0002）

操作按键
移动窗口 左/下/上/右Mod+Shift+h/j/k/l
水平分屏（新窗口在右）Mod+z
垂直分屏（新窗口在下）Mod+v
切回平铺 / 切分屏方向Mod+e
标签页（tabbed）布局Mod+w

记法：v = vertical（垂直）→ 新窗口在下；z = 剩下的水平 → 新窗口在右。口诀：「v 往下，z 往右」。

工作区进阶（0003）

操作按键
切到上/下一个工作区Mod+Ctrl+h / l
把窗口搬到工作区 N（自己不跟）Mod+Shift+1…0
搬窗口到上/下个工作区并跟过去Mod+Ctrl+Shift+h / l
全屏切换Mod+f

调整与浮动（0004）

操作按键
进入 resize 模式Mod+r，然后 h/l 调宽度、j/k 调高度，Esc 退出
平铺 ↔ 浮动切换Mod+Shift+Space

rofi 与杂项（0005）

操作按键
应用启动器（兜底）Mod+g
表情 / 符号输入Mod+Shift+g
计算器（失效：rofi-calc 未装）Mod+Alt+6，改用 echo $((…))
scratchpad 收起 / 调回Mod+Shift+- / Mod+-
截图（全屏 / 选区）Mod+Home / Mod+Shift+Home
键盘布局切换Mod+`（grave）
放大镜Mod+x

完整键位见 USAGE.md 和 config。官方默认键位对照见 i3 Reference Card。
