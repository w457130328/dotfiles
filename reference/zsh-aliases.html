zsh 别名速查表

来源：zsh/.aliases。打印出来贴桌上，用于间隔复习。三类别名：全局（alias -g，命令任意位置）、普通（alias，命令开头）、后缀（alias -s，按文件后缀）。

全局别名：管道后缀（0006 已学）

别名展开成用途
L| less分页
H| head开头几行
H2| head -n 20前 20 行
G| grep过滤
Gi| grep -i忽略大小写过滤
GH| grep HTTP过滤 HTTP 行
C| clipcopy复制到剪贴板
A1| awk '{print $1}'取第一列
X| xargs -I@逐项传参
Fj| jq .JSON 格式化
Fy| yq .YAML 格式化
Fx| xmllint --format -XML 格式化
V| vim -结果送进 vim

普通别名：命令开头（0008 已学）

别名展开成用途
ccat看文件
vvim编辑
v.vim .打开当前目录
leless -j4分页
szsource ~/.zshrc重载配置
hhash -rf清命令缓存

后缀别名：按文件后缀（0008 已学）

⚠️ 图形打开类（pdf/png/html/mp4/办公文档）因程序未装失效；只有命令行查看类能用：

后缀实际执行状态
jarjava -jar✓ 可用
zip / warunzip -l（列清单）✓ 可用
gz / tgztar -tf（列清单）✓ 可用
pdfbackground mupdf✗ mupdf 未装
png / jpgbackground gpicview✗ gpicview 未装
mp4 / mkvbackground vlc✗ vlc 未装
htmlbackground chromium✗ chromium 未装
办公文档background libreoffice✗ libreoffice 未装

快捷键（bindkey，0007 已学）

按键效果
Ctrl+K清屏 + exa -al
Ctrl+J / Ctrl+H清屏 + 目录树 2 / 3 层
Ctrl+T / Esc 再 Ctrl+T插入日期 / Unix 时间戳
Ctrl+G清屏 + git status

完整别名见 zsh/.aliases；快捷键定义见 shortcuts.zsh。
